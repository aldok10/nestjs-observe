# Standalone Example

Menjalankan logger framework-independent dengan `@aldok10/nestjs-observe-logger-core` dan `@aldok10/nestjs-observe-logger-transports`.

## Jalankan

Dari root repo (setelah dependency terpasang/build sesuai kebutuhan workspace):

```bash
node examples/standalone/index.mjs
```

Contoh ini membuat channel `app` dan `audit`, menulis log ke file sementara, dan menampilkan ringkasan output.
